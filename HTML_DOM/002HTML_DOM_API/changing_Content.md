# HTML DOM - Changing Content

## Changing HTML
allows JS to change both text and content of HTML elements
done by using innerHTML property.
synatx:
`document.getElementById(id).innerHTML = new HTML`

innerHTML can be used to change any HTML element including the tags like `<html>` and `<body>`

DOM element needs to exist before accessing it.

change content of `<p>` element
`document.getElementById("p1").innerHTML = "New text!";`

## changing attribute
change attribute of an element

an attribute is the value you can give to a HTML element like src. its found within the <>
syntax:
`document.getElementById(id).attribute = new value`

example:
`<img id="myImage" src="Gif.gif">`

`<script>`
`document.getElementById("myImage").src = "Image.jpg";`
`</script>`

## document.write()
In JS document.write() can be used to write directly to a HTML output stream. this will display what wants to be written directly on the webpage
However, document.write() after the document is loaded will overwrite the document.

# changing CSS

## HTML style
`document.getElementById(id).style.property = new style`

## Using Events
HTML DOM allows devs to execute code when an event occurs
Events are generated by the browser when something happens to HTML elements.
* Element is clicked on
* page is loaded
* input fields are changed

`<button type="button" onclick="document.getElementById("id1").style.color = "red">click</button>`
if button is clicked then the id1 text will change color
