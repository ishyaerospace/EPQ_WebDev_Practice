# events
syntax:
`<element event='JavaScript code'>`

example:
`<button onclick="document.getElementById('demo').innerHTML = Date()">The time is?</button> `
and 
`<button onclick="this.innerHTML = Date()">The time is?</button>`

events:
onchange = an HTML element has been changed
onclick = the user has clicked the HTML element
onmouseover = user moved mouse over a HTML element
onmouseout = user moves the mouse away from the HTML element
onkeydown = user pushes a keyboard key
onload = the browser has finished loading the page.

... many others aswell that can be found in JavaScript reference HTML DOM Events

Event handlers can be used to handle and verify user input, user actions, and browser actions:
* things that should be done every time a page loads
* things that should be done when the page is closed
* Action that should be performed when a user clicks a button
... many more

many different methods can be used to let JS work with events
* HTML event attributes can execute JS code directly
* HTML event attrivutes can call JS functions
* you can assign own event handler functions to HTML elements
* you can prevent events from being set or being handled
... many more

## mouse events
click, dblclick, mouseover, mouseout, mousemove, mousedown, mouseup, mouseenter, mouseleave, contextmenu, wheel, drag events

Let box listen for mouseover
`box.addEventListener("mouseover", function () {`
`  box.innerHTML = "Mouse is over me!";`
`});`

Let box listen for mouseout
`box.addEventListener("mouseout", function () {`
`  box.innerHTML = "Move is out!";`
`});`

## keyboard
event.key = returns the value of the key - if z is pressed it will return z or Z if shift is held
event.code = returns the key code - always returns "KeyZ"
you can also check modifier keys like shift and alt.

`in01.addEventListener("keydown", function (event) {`
`// If event.code was "enter", then display text`
`  if (event.code === "Enter") {`
`    document.getElementById("demo").innerHTML = "Enter was pressed!";`
`  }`
`});`

# loading

## DOMContentLoaded
DOMContentLoaded event fires when the browser has fully loaded the HTML and built the Document Object Model (DOM) tree, but has not necessarily finished loading external resources like images and stylesheets.

The DOMContentLoaded event is best for initialising the user interface, attaching event handlers and performing actions that only requite the DOM to be ready.

`document.addEventListener("DOMContentLoaded", function () {`
`  document.getElementById("demo").innerHTML = "HTML is loaded!";`
`});`

## window load
load event fires when the entire page has fully loaded, including all dependent resource such as images, stylesheets and syb-frames <-- this may be usefull to me as my dashboard will rely on images to be ready before user can access dashboard content.

`window.addEventListener("load", function () {`
`  document.getElementById("demo").innerHTML = "Page is fully loaded!";`
`});`

other load events:
`<image>` fires when an image has finished downloading
`<script>` fires when a script has been successfully loaded and executed
`<link>` fires when stylesheet has been fully loaded and parsed

# timing events
timing events let code run:
* after delay
* repeatedly

generated by system clock.

## timer functions
setTimeout() = sets a clock timeout (runs once)
setInterval() = sets a clock interval (runs repeatedly)
clearTimeout() = clears a timeout
clearInterval = clears an Interval

these belong to window object.

setTimeout(function, delay, optional arguaments that can be passed to function) --> returns integer (timeout ID)
setInterval(function, delay, optional arguaments passed to function) --> return integer (timeout ID)
clearTimeout(return value of setTimeout)
clearInterval(return value of setInterval)

# managing events

adding events:
`element.addEventListener("event", function, useCapture=bool)`

removing events:
`element.removeEventListener("event", function)`

blocking events:
`element.addEventListener("event", function(event){`
`    event.preventDefault();`
`    document.getElementById("demo").innerHTML = "element blocked";`
`})`
