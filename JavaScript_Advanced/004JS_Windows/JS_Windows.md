# BOM Browser Object Model

## Window Object
supproted by all browsers: represents the browser's window.

`window.document.getElementById("header");` is the same as `document.getElementById("header");` as window contains all the global functions as methods.

## window size
`let w = window.innerWidth;` - inner width of browser window (in pixels)
`let h = window.innerHeight;` - inner height of browser window (in pixels)
`window.open()` - open a new window
`window.close()` - close the current window
`window.moveTo()` - move the current window
`window.resizeTo()` - resize the current window
